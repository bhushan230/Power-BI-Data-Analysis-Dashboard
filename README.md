# 📊 Power BI Data Analysis Dashboard

## 📌 Project Overview

This project is a **Power BI Data Analysis Dashboard** designed to analyze sales transactions, product quantities, and brand-wise performance. The dashboard provides clear visual insights that help understand business performance, trends, and decision-making metrics.

The project demonstrates **data cleaning, modeling, visualization, and business insight generation** using Power BI.

---

## 🎯 Objectives

* Analyze transaction data effectively
* Visualize quantity and sales trends
* Compare brand-wise performance
* Create an interactive and user-friendly dashboard
* Generate insights for business decision-making

---

## 🛠️ Tools & Technologies Used

* **Power BI** – Data visualization & dashboard creation
* **Microsoft Excel / CSV** – Data source
* **GitHub** – Project version control & sharing

---

## 📈 Dashboard Features

* 📌 Total Transactions Overview
* 📦 Quantity Analysis by Product
* 🏷️ Brand-wise Performance Comparison
* 📊 Interactive charts & filters
* 🔍 Clean and professional layout
